# Captures documentaires

Les images de ce dossier utilisent uniquement des données fictives. Elles sont des maquettes
documentaires générées pour illustrer les parcours et ne constituent pas une référence visuelle
pixel par pixel de la version déployée.

| Fichier                       | Parcours illustré                                    |
| ----------------------------- | ---------------------------------------------------- |
| `coffre-factice.webp`         | comptes, actions rapides et export chiffré           |
| `deverrouillage-factice.webp` | saisie locale de la phrase dans un coffre verrouillé |

Avant chaque ajout, vérifier l'absence de secret, adresse personnelle, chemin local, identifiant
réel ou métadonnée sensible. Les logins éventuels doivent utiliser le domaine réservé
`example.test` et les secrets doivent rester masqués.
