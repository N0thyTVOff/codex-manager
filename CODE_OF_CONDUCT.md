# Code de conduite

## Notre engagement

Nous souhaitons un espace accueillant, respectueux et exempt de harcèlement, quels que soient
l'expérience, l'identité, l'origine, le handicap, la religion ou les opinions exprimées de bonne
foi sur le projet.

## Comportements attendus

- rester courtois et précis ;
- critiquer les idées et le code, jamais les personnes ;
- respecter la confidentialité et ne publier aucune donnée sensible ;
- accepter les décisions de maintenance et aider à corriger ses erreurs.

Le harcèlement, les attaques personnelles, la publication d'informations privées et tout contenu
discriminatoire sont interdits.

## Application

Signalez confidentiellement un incident au mainteneur via son profil GitHub
[`@N0thyTVOff`](https://github.com/N0thyTVOff). Le mainteneur peut modifier ou supprimer un contenu,
fermer une discussion ou limiter la participation afin de protéger la communauté.
